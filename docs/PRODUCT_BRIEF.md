## 초대 링크 전화번호 연동 화면

- 마지막 확인: 2026-11-07
- 핵심 사용자: 폭염 현장 작업자 (출처: `README.md`의 개요, 2026-11-07 확인)
- 왜 중요한지: 초대 리다이렉트로 연동을 시작하는 동작과 링크 없는 일반 로그인 흐름을 구분한다. (출처: 사용자 확인 답변, 2026-11-07)
- 가장 중요한 것: `heatguard://team/invitations/{token}` 리다이렉트가 있을 때만 전화번호 연동으로 이동한다. 이미 인증된 `TEAM_MEMBER`는 연동 화면으로 바로 이동하고, 로그아웃 상태면 로그인 후 연동 화면으로 이어진다. 링크 없이 로그인하면 일반 홈 흐름으로 이동한다. 전화번호 `010-1234-5678` placeholder는 회색이며, 실제 입력값은 `strongText`로 유지한다. (출처: 사용자 확인 답변, 첨부 스크린샷, `README.md`, `app/src/main/java/com/nativelap/heartguard/navigation/HeartGuardNavHost.kt`, 2026-11-07)
- 포기할 수 있는 것: 초대 리다이렉트가 없으면 일반 로그인 뒤 전화번호 연동을 시작하지 않는다. (출처: 사용자 확인 답변, 2026-11-07)
- 이렇게 한 이유: 사용자가 전화번호 연동은 특정 초대 리다이렉트에 한정하고, 링크 없는 로그인은 일반 홈으로 이어지도록 확인했다. (출처: 사용자 확인 답변, `app/src/main/java/com/nativelap/heartguard/navigation/HeartGuardNavHost.kt`, 2026-11-07)
